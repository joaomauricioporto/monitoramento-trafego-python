Instituição de Ensino

Data: Março de 2026

1. Resumo

Este trabalho apresenta o desenvolvimento de um sistema de monitoramento de tráfego urbano criado em Python. O projeto permite registrar e analisar dados relacionados ao fluxo de veículos em diferentes locais e horários, além de gerar estatísticas e relatórios que ajudam a compreender padrões de trânsito. O sistema possui uma interface gráfica desenvolvida com CustomTkinter, permitindo a inserção e visualização de dados de forma interativa e organizada.

2. Introdução

O monitoramento de tráfego urbano é uma atividade essencial para o planejamento e gestão de cidades modernas. A análise de dados sobre o fluxo de veículos, velocidade média e ocorrências permite identificar padrões importantes que auxiliam na tomada de decisões relacionadas à mobilidade urbana.

Este projeto foi desenvolvido com o objetivo de simular um sistema simples de monitoramento de tráfego urbano. A aplicação permite registrar leituras contendo informações como local, horário, fluxo de veículos, velocidade média e possíveis ocorrências (como acidentes ou obras).

A partir dessas informações, o sistema realiza análises automáticas que ajudam a identificar padrões importantes no trânsito, como horários de pico, média de fluxo de veículos e número de ocorrências registradas. Além disso, o projeto também foi desenvolvido com foco na prática de organização de código em múltiplos módulos, separando responsabilidades entre interface gráfica, lógica de negócio, estrutura de dados e funções auxiliares.

3. Objetivos

3.1 Objetivo Geral

Desenvolver um sistema de monitoramento de tráfego urbano utilizando Python, capaz de registrar, armazenar e analisar dados relacionados ao fluxo de veículos em diferentes locais e horários.

3.2 Objetivos Específicos

  • Implementar uma interface gráfica intuitiva para inserção e visualização de dados;
  • Desenvolver funcionalidades para registro de leituras de tráfego com informações relevantes;

  • Gerar relatórios detalhados sobre o comportamento do tráfego urbano.

5. Estrutura do Projeto

O repositório está organizado da seguinte forma, permitindo uma separação clara entre as diferentes responsabilidades do sistema:

  • gui.py: Contém toda a interface gráfica da aplicação, incluindo os componentes visuais e a interação com o usuário;
  • main.py: Versão alternativa do sistema executada via terminal, permitindo o uso sem interface gráfica;
  • models.py: Responsável pela estrutura de armazenamento das leituras de tráfego, definindo as classes de dados;
  • services.py: Contém as regras de negócio e funções de processamento de dados, incluindo análises estatísticas;
  • utils.py: Funções auxiliares utilizadas para validação de dados e outras operações de suporte.

Essa organização permite uma separação clara entre as diferentes responsabilidades do sistema, facilitando futuras melhorias e manutenção do código. A arquitetura modular também facilita o entendimento do código e permite que diferentes desenvolvedores trabalhem em módulos distintos simultaneamente.

6. Funcionalidades do Sistema

O sistema permite realizar diversas operações relacionadas ao monitoramento de tráfego, incluindo:

  1. Registro de novas leituras de tráfego: Permite inserir dados sobre local, horário, fluxo de veículos, velocidade média e ocorrências;
  2. Consulta de leituras por local: Busca e exibe todas as leituras registradas em um local específico;
  3. Consulta de leituras por horário: Permite filtrar leituras por faixa horária;
  4. Cálculo de média de fluxo de veículos: Realiza análise estatística do fluxo médio de veículos;
  5. Identificação da menor velocidade registrada: Identifica pontos com velocidade média mais baixa;
  6. Contagem de ocorrências registradas: Totaliza o número de incidentes reportados;
  7. Identificação de horário de pico: Determina automaticamente os horários com maior fluxo de veículos;
  8. Geração de relatórios detalhados por local: Cria relatórios completos com todas as informações relevantes.

7. Como Executar o Projeto

Para executar o projeto em seu ambiente local, siga os passos abaixo:

7.1 Clonagem do Repositório

git clone https://github.com/joaomauricioporto/monitoramento-trafego-python.git cd monitoramento-trafego-python

7.2 Configuração do Ambiente Virtual (Opcional)

python -m venv venv source venv/bin/activate # Para Linux/macOS # venv\Scripts\activate # Para Windows

7.3 Instalação de Dependências

pip install customtkinter

7.4 Execução do Sistema

Com interface gráfica:

python gui.py

Via terminal:

python main.py
